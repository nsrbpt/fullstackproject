# Exam Seating Allocation System – Project Documentation

## 1. Project Overview
A full-stack MERN application for automated exam seating with zig-zag interleaving, QR code generation, and professional PDF reporting.

## 2. Key Features
- **Mission Control Dashboard**: Dynamic statistics and quick-access to recent allocations.
- **Zig-Zag Algorithm**: Column-wise placement with departmental separation.
- **Seating Archive**: Permanent storage and retrieval of all exam grids.
- **Roll Number Display**: Grids show student roll numbers directly for easy verification.
- **QR Identification**: Unique QR codes for every student seat.

## 3. Tech Stack
- React, Tailwind, RTK-Query
- Node.js, Express, MongoDB, JWT
- jsPDF, QRCode

## 4. How to use
1. Login as Admin.
2. Upload student roster in Data Ingestion.
3. Generate allocation on Dashboard.
4. View/Print results from the Seating Grids archive.
